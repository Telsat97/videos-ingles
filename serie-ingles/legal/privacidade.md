# Política de Privacidade – Inglês Fácil

Última atualização: 21 de outubro de 2026

O **Inglês Fácil** é um aplicativo de uso pessoal do responsável pelo canal do YouTube
**@querumoseguir** (https://www.youtube.com/@querumoseguir). Ele serve apenas para publicar,
de forma automática, os vídeos educativos de inglês produzidos pelo próprio canal.

## Quais dados o aplicativo acessa

O aplicativo usa os Serviços de API do YouTube e a API do Google Drive, com a autorização
do dono do canal, apenas para:

- **enviar vídeos** ao canal do próprio responsável (permissão `youtube.upload`);
- **guardar uma cópia dos vídeos** no Google Drive do próprio responsável, em arquivos criados
  pelo aplicativo (permissão `drive.file`).

O aplicativo **não** lê, coleta, armazena ou compartilha dados de espectadores, inscritos ou
de qualquer outra pessoa, e não acessa outros arquivos do Google Drive.

## Como os dados de acesso são guardados

As credenciais de acesso ficam guardadas de forma criptografada nos segredos do GitHub do
responsável e são usadas somente para publicar os vídeos. Elas não são vendidas, compartilhadas
ou usadas para publicidade.

## Serviços de terceiros

Ao usar este aplicativo, você também está sujeito à **Política de Privacidade do Google**
(https://policies.google.com/privacy) e aos **Termos de Serviço do YouTube**
(https://www.youtube.com/t/terms).

## Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google:
https://myaccount.google.com/permissions
